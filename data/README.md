# Data

This directory contains the **IBM Telco Customer Churn** dataset used in this project.

**File:** [`telco_customer_churn.xlsx`](./telco_customer_churn.xlsx)

**Source:** Kaggle: <https://www.kaggle.com/datasets/yeanzc/telco-customer-churn-ibm-dataset>

The dataset contains **7,043 customer records** and is used to predict the binary target `Churn Value`.
